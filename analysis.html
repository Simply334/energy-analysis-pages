03｜基础数据逻辑：能耗核算、能效、峰谷电价、新能源测算、碳排计算

这一部分是智慧能源平台、项目测算、可视化看板、碳管理报告的底层计算逻辑。

3.1 能耗核算

能耗核算的第一步是确定边界、能源品种、计量点和时间周期。综合能耗通常按 GB/T 2589-2020 进行折标，标准状态为现行，实施日期为 2021-04-01 [S5]。

综合能耗 = Σ（能源实物量 × 折标系数） 单位强度 = 综合能耗 / 面积、产量、产值或人数 总分表闭合率 = 分项计量合计 / 总表计量
注意：外购电、光伏自用、光伏上网、储能充放电不能简单相加；储能充电不是最终能源消费，放电也不是新增能源生产。

3.2 能源能效分析

能耗是“用了多少”，能效是“用得是否有效”。能效分析必须结合产量、天气、运行小时和工况。

冷站 COP = 供冷量 / 冷站总电耗 单位产品电耗 = 生产用电量 / 合格产品产量 空压单耗 = 空压站电耗 / 产气量 光伏 PR = 实际发电量 / 理论发电量 储能往返效率 = 放电量 / 充电量

判断逻辑：总量看规模，结构看对象，强度看效率，对标看差异，归因看原因。

3.3 峰谷电价与需量管理

峰谷电价分析必须使用 15 分钟或小时负荷曲线，并结合电度电费、基本电费、需量电费、力调电费。电力需求侧管理办法强调节约用电、需求响应、绿色用电、电能替代、智能用电、有序用电 [S6]。

总电费 = 电度电费 + 基本/需量电费 + 力调电费 + 基金附加 负荷率 = 平均负荷 / 最大负荷 峰谷差率 =（最大负荷 - 最小负荷）/ 最大负荷

最大需量高但持续时间短 → 储能削峰；峰段电量高 → 错峰生产；夜间基荷高 → 排查待机、泄漏和未关闭设备。

3.4 新能源发电与储能收益测算

光伏可装容量 = 可利用屋顶面积 × 单位面积装机密度 × 修正系数 年发电量 = 装机容量 × 等效利用小时 × 系统效率 光伏收益 = 自用电量 × 替代电价 + 上网电量 × 上网电价 - 运维成本 储能收益 = 峰谷套利 + 需量收益 + 光伏消纳收益 + 需求响应收益 - 损耗与衰减成本

光伏看自用率和屋顶资源；储能看峰谷价差、最大需量、调度次数、电池寿命和消防并网。

3.5 碳排放计算

碳排放核算要区分组织碳盘查、项目减排量和产品碳足迹。国家正在推进从能耗双控向碳排放双控转变，并健全企业、项目、产品层面的核算机制 [S8]。

碳排放量 = 活动数据 × 排放因子 Scope 1 = 燃气、柴油、煤等直接燃烧排放 Scope 2 = 外购电力、外购热力间接排放 项目减排量 = 基准情景排放量 - 项目实施后排放量

3.6 产品碳足迹计算

产品碳足迹核算不是只算生产用电，而是看生命周期。生态环境部已发布产品碳足迹核算标准编制工作指引，推动统一规范的产品碳足迹标准体系 [S9]。

产品碳足迹 = Σ（活动数据 × 排放因子 × 分摊系数） 生命周期边界 = 原材料 → 运输 → 生产 → 包装 → 使用 → 回收处置

关键难点：边界定义、排放因子版本、供应商数据、共线生产分摊、绿电和绿证披露。

05｜能源项目数据设计：前期测算、方案设计、商务报价、落地验收

综合能源项目、光伏储能、工业节能、微电网、碳足迹和碳治理，底层都需要“基线-方案-收益-验证-运营”闭环。

5.1 综合能源托管

核心是基准能源费用、责任边界、服务质量和节能收益分配。

托管收益 = 托管服务费 + 节能分享收益 - 改造投资摊销 - 运维成本 - 能源价格与工况风险

适用：医院、学校、园区、商业体风险：基准期不合理、业务变化、价格波动

5.2 工业节能改造

核心是基线能耗、调整项、设备效率和节能量验证。

真实节能量 = 调整后基准能耗 - 改造后实际能耗 年度节能收益 = 节能量 × 能源单价 + 运维成本下降

冷站空压锅炉电机

5.3 光伏储能项目

光伏看自用率和屋顶资源，储能看峰谷价差、需量削峰和调度能力。

光伏收益 = 自用电量 × 替代电价 + 上网电量 × 上网电价 - 运维成本 储能容量 ≈ 目标削峰功率 × 放电小时数

四可要求 [S4]新能源上网电价市场化 [S7]

5.4 微电网项目

核心是源网荷储能量平衡、关键负荷保障、新能源消纳和综合供能成本。

负荷需求 = 光伏 + 风电 + 储能放电 + 外购电 + 备用电源 - 储能充电 - 弃电

自平衡率新能源渗透率孤岛运行时长

5.5 碳足迹核算

核心是产品生命周期边界、BOM、供应商因子、共线生产分摊和数据质量等级。

单位产品碳足迹 = 生命周期各阶段碳排合计 / 合格产品数量

原材料生产运输使用与处置

5.6 碳排放治理

核心是组织碳盘查、碳预算、绿电策略、节能降碳项目库和减排路径。

减排缺口 = 预测碳排放量 - 目标碳排放量 碳成本 = 碳配额缺口 × 碳价

09｜综合结论：你要建设的是“能碳数据产品体系”

把所有板块串起来，最终目标不是做一份报告，而是形成持续复用的数据分析、方案测算、项目管理和可视化交付能力。

一句话总结：以统一对象编码、计量关系和指标口径为底座，把能耗核算、能效诊断、峰谷电价、新能源测算、储能调度、碳排核算、项目收益和可视化报表统一起来，形成服务综合能源托管、节能改造、光伏储能、微电网、碳足迹和碳治理的能源数据产品体系。
